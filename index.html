Content Manager

Content Manager is a desktop application for organizing local video content and publishing authorized content to supported social platforms.

What it does

Content Manager lets users select and organize video files stored on their computer, configure publishing options, and publish content to an account after the user has explicitly connected and authorized that account.

For TikTok, the application uses TikTok's official developer APIs and OAuth authorization. Users decide which TikTok account to connect and grant the permissions requested by the application.

TikTok integration

The TikTok integration is intended for publishing and managing the user's own content. Where supported by TikTok's APIs, Content Manager can retrieve information about the user's published videos and publishing status.

Content Manager does not claim to be affiliated with or endorsed by TikTok.
